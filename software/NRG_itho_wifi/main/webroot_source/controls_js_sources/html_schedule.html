Fan schedule

Set a weekly schedule for the fan speed. Select a speed below and click or drag over the grid to paint the time slots (30 minutes per cell). Click a day name to fill the whole day.

The schedule only sends a speed command when the scheduled speed changes. A speed selected in between with a remote (or the API / web interface) stays active until its timer expires or until the next change in the schedule. Slots set to No change leave the fan as it is.

The device time is not synchronised yet; the schedule is paused until it is. Check the NTP server and timezone in WiFi setup.
